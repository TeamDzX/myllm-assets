Bin

Things you deleted, until you empty it

Rewind lists files that have been overwritten or deleted by an app, the Shell or the assistant. The workspace keeps the last few versions of each file in a hidden .history folder; Restore puts one back, and the current version is kept too, so a restore can itself be undone.

The Bin is the hidden .trash folder in your shared workspace. The Shell app's rm and rmdir put things here instead of deleting them. Restore puts a file back where it came from; Delete and Empty Bin are final.
