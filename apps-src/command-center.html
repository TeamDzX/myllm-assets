How systems report

A system reports by writing one small JSON "heartbeat". The hub reads every heartbeat in the shared registry and shows it below. Two ways in:

On this device — another MyLLMos app writes straight to the shared file store (private, no network):


    
From anywhere — an outside system (Pi, server, cron) posts one line to your
      Telegram bot. The message must start with MYLLM: followed by the JSON:

    


    
The heartbeat schema (transport-agnostic — same shape however it arrives):
      
• id — unique system name
      
• status — "ok" · "warn" · "error"
      
• metrics — any key→number/text (shown as chips)
      
• errors — optional list of strings
      
The hub stamps the time it arrives.
